# 星空亚马逊 Agent · Codex 版

**在官方 Codex 中，把选品、文案、视觉、广告与运营巡检连成一条有证据、能落盘的工作流程。**

作者：坚哥｜公众号「跨境者说干货」｜知识星球「星空的跨境圈子」

本仓库是 **Codex 版公开介绍与下载入口**。Windows 和 macOS 安装包一起发布；下载安装器无需加入私有开发仓。**安装、更新需要联系坚哥取得本机授权码。**

## 能做什么

| 板块 | 解决的问题 | 主要交付物 |
| --- | --- | --- |
| S1 选品 | 这个品能不能做、哪里采购、哪些风险要先查 | 市场报告、供应商评估、产品画像与可行性分析 |
| S2 文案 | 买家搜什么、标题和五点怎么写 | 关键词包、中英 Listing 文案与校验结果 |
| S3 视觉 | 主副图、A+、短视频怎么表达产品 | 视觉方案、提示词与分镜；实际出图依赖已配置工具 |
| S4 广告 | 广告怎么搭、怎么诊断、Bulk 怎么生成 | 策略、Campaign 架构、待审核 Bulk 与排错报告 |
| S5 运营 | 日常要看什么、库存与广告哪里异常 | 巡检快照、问题清单与待审核建议 |

36 个 Skill 目录包含业务技能、入口、内部编排与共享契约。缺数据会说明缺什么，不编造销量、CPC 或店铺表现。广告文件由你审核后自行上传；系统不代替你付款、发货或改后台。

## 开始使用

1. 安装并打开一次官方 Codex，登录你自己的账号；准备 Python 3.11 或更新版本。
2. 下载对应平台 ZIP，完整解压；运行“申请授权”，将本机申请码发给坚哥。
3. 收到 `SKYC1.` 开头的授权码，运行“安装与更新”，完整粘贴授权码。安装器会建立专用依赖环境。
4. 需要 1688 抓取时运行“安装1688”；市场数据 MCP 使用你自己的服务商配置。
5. 完全退出再打开 Codex，在产品文件夹里新建会话，输入 **启动星空**。

你仍在官方 Codex 里选择模型、管理任务和查看工作区。星空安装器不包含 Codex 账号、不包含模型额度、不重新分发官方 Codex 程序。

## 数据与使用边界

报告和产品文件保存在你选择的本地工作区。使用官方 Codex、模型和外部 MCP 时，相关请求会发送给你配置的服务；本页不承诺“业务数据绝不离开本机”。

公开 ZIP 内的业务载荷使用 AES-256-GCM 加密，包内不附解密密钥。安装器验证作者签发的本机授权码，再用该授权所携带的对应版本解密权限安装。拿到公开下载包不等于拿到业务文件。

离线更新到采用新密钥的版本时，需联系作者换发对应版本授权码；有效服务期内如何换发以购买约定为准。授权码请作为秘密保存。Codex 安装后需要读取本地 Skill，已授权用户仍能复制解密后的文件；本方案不能阻止已授权者转发，也不承诺不可破解。公开下载不等于开放源代码许可。

私有开发仓继续保留；本公开仓只放介绍、使用文档和经过筛选的发行物，不包含私钥、签发记录、开发历史或客户数据。
