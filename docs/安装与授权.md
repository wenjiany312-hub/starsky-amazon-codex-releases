# 星空 Codex · 安装、授权与更新

版本：2.6.0-rc.2，Windows/macOS 会员测试版。rc.1 已有两平台安装与授权记录；本次修订后的 Mac 更新、新任务加载和完整业务流程仍待实测。

## 下载后先看使用说明

完整解压后，先双击 **00-使用说明.html**。包内还有 `01-口令速查.html`、`02-MCP配置必读.html`、`03-MCP优惠购买入口.html` 及各自 TXT。HTML 可离线阅读并复制口令；安装后会保留说明副本。

业务 Skill 封装在 `payload.enc` 中，公开包里不显示明文 Skill 属于正常现象。授权安装后，官方 Codex 会从实际插件目录读取 36 个 Skill；请在新任务中核实加载版本，不要仅凭出现 S1–S5 菜单就认定全部流程通过。

## 先准备

- 官方 Codex 桌面版，已打开并登录。星空不提供账号或模型额度。
- Python 3.11+。Windows 从 python.org 安装时勾选 Add python.exe to PATH；Mac 从 python.org 安装。
- 联网下载插件与 Python 依赖。无需加入私有 GitHub 仓，也不需要提供 GitHub token。
- 安装器下载页：https://github.com/wenjiany312-hub/starsky-amazon-codex-releases/releases

当前交付是 ZIP 内的脚本安装器，不是已签名 exe/dmg。不得把它描述为已经通过微软或 Apple 的代码签名认证。视频合成另需用户安装 FFmpeg；市场数据与出图服务按实际任务配置。

## Windows

完整解压 Windows ZIP 到普通文件夹，双击 `申请授权.bat`，复制显示的本机申请码。

联系公众号「跨境者说干货」后台，或知识星球「星空的跨境圈子」私信坚哥，发送“Codex 版、Windows、本机申请码”。收到 `SKYC1.` 开头的授权码后，双击 `安装与更新.bat`，按提示粘贴。初次依赖安装需要联网，失败后可重试。

## Mac

完整解压 Mac ZIP。可尝试双击 `申请授权.command`；如果文件关联或执行权限导致打不开，请打开终端，输入 `bash `（最后有空格），把该 `.command` 文件拖进终端，再回车。

收到授权码后同样运行 `安装与更新.command`。终端路径包含空格或中文时请保留引号，或使用上面的拖入方式。安装器不会自动删除 macOS 隔离属性或绕过系统安全设置。

Apple 芯片/Intel 的 Python 解释器需与本机匹配，依赖会按当前解释器安装；当前没有覆盖所有芯片和系统组合。rc.2 已统一授权日期为北京时间，并补充查找官方 ChatGPT.app 内置兼容 Codex CLI，电脑可保留自己的时区。先按正常入口运行；仍报错时按包内说明核对本机 CLI，不要随意下载不明程序。

## 装完后

1. 需要抓取 1688 商品时运行 `安装1688.bat` / `安装1688.command`，安装 Chromium 并写入对应 MCP 配置。旧配置先备份，只更新 1688 的表段，保留其他 MCP 和登录态。
2. 按 `02-MCP配置必读` 配置本系统 S1/S2/S4 所需 Sorftime、SIF；卖家精灵/西柚按选定词库路线加装，领星用于相应运营数据任务。使用自己的服务和凭据；购买渠道见 `03-MCP优惠购买入口`，不要把优惠码填成 API Key，不在公开 Issues 上传凭据。
3. 运行 `一键体检`。它只检查本机安装与依赖，不会发送飞书消息，也不会把配置存在等同于服务认证通过。
4. 完全退出再打开官方 Codex，在产品文件夹中新建会话输入“启动星空”。让新会话确认实际加载版本和工具能力。

## 配置放哪里

- 星空用户目录：`~/.starsky-codex/`。Windows 的 `~` 指当前用户目录。
- 领星配置：`~/.starsky-codex/config/lingxing_config.yaml`；初始为空模板，填写你的 AppID/AppSecret 和店铺范围。
- 授权记录：星空用户目录的 `license.json`，不要公开分享。
- 专用运行环境：星空用户目录的 `runtimes/`；不会往全局 Python 安装依赖。
- 安装状态：`~/.codex/starsky-codex.json`；设置了 `CODEX_HOME` 时使用该目录。记录实际插件缓存、专用 Python 和配置路径。
- 产品资料与已生成报告：仍在你自己选择的产品工作区，安装器不删除它们。

## 原来装过私有版

新安装器检测到其他市场仍启用了同名星空插件时会停下，避免同时加载两套 Skill。**不要直接删旧插件目录或用户配置。** 联系作者先备份领星配置并迁移，原私有仓不会因公开版安装而改变。当前预览版优先面向新用户环境；旧版迁移需作者协助。

## 更新与授权到期

在官方 Codex 中输入“启动星空”，入口 Skill 会调用本机更新检查器，检查作者签名的公开发行清单。有新版时提示版本和更新说明链接，再继续业务；不会自动安装或打断工作。网络失败会说明未能确认更新，继续使用当前版。该提醒发生在调用星空入口时，不需要后台常驻程序；新会话能否实际执行检查仍需在你的 Codex 环境验收。

运行 `检查新版` 会读取发行清单，并可进入更新流程；启动星空时的更新提醒本身不会安装。测试 rc.2 建议直接下载完整新版包，保留原产品项目与配置，运行新包的“安装与更新”，成功后完全退出并重开 Codex，在同一个产品项目中新建任务。

**从 rc.1 升级：**发送“rc.2 更新 + 平台 + 本机申请码”给作者，领取 rc.2 授权。旧码不包含本次新版解密权限。不要把新版单个脚本拷进旧签名包。

公开包只提供 AES-256-GCM 加密的业务载荷，解密权限由作者签发的授权码携带，不随安装器公开。新版换用新密钥时，安装器会提示联系作者换发对应版本授权码。请将当前版本号和本机申请码一起提供给作者；换发是否包含在服务期内以购买约定为准。

授权码和本机 `license.json` 都含有保密的解密信息，不要分享或上传。解密后的 Skill 必须供 Codex 本地读取，所以授权用户仍能复制文件；设备检查不能被解释成防止人为转发的绝对保障。

安装、重装、更新及重新运行“安装1688”入口需有效的本机授权。到期后已安装内容仍可在 Codex 使用，也仍可检查更新；取得新版授权后再安装。测试授权的到期日不等于到期自动删除或停止已安装内容。换电脑需重新申请，DSH 的 `STARSKY1.` 和旧版 `SKY1.` 授权码不适用于本发行版的 `SKYC1.`。

下载、验签、依赖或 CLI 安装失败会返回错误，不应显示安装成功。旧版本目录会保留；如自动恢复未完成，请把不含凭据的错误信息发给作者，不要清空 `.codex`。
