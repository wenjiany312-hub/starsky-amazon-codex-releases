# 星空 Codex 2.6.0-rc.4 · 会员服务期更新

本版建立会员更新凭证链路，保留 rc.3 的省额度工作流。Windows/macOS 共用业务载荷与会员规则，保持 Pre-release。

## 本次变化

- 有效会员保存一次原激活记录，后续发行通过 GitHub 取得本机加密更新凭证，无需逐版本领取新码。
- 固定版本试用不推送后续版本，也不自动获得新版安装权限；试用及服务到期均不删除已装内容。
- 原正式客户按原到期日迁移；内部测试默认排除，明确指定的测试设备单独登记，不自动延长期限。
- 作者发码助手新增会员／固定版本试用选项和“同步 Codex 会员更新凭证”。会员续费可延续原设备激活记录。
- 原激活与当前版本许可分开保存；签名、设备、期限、目标版本、包摘要逐项核验。网络失败保留旧版，不误报过期。
- 延续按需导航、Terra 中日常／Astra 中分析、限定字段小改和真实数据审核门禁，不自动切换模型。

## 旧版用户这一次怎么升级

**rc.1–rc.3 用户直接下载本页对应 Windows/macOS ZIP，完整解压，运行新包“安装与更新”。** 已登记的有效会员会读取原码并自动核验，无需领取 rc.4 新码。旧版“检查新版”尚不支持此次会员迁移；不要下载 Source code，也不要只替换单个脚本。

看到 `安装完成：2.6.0-rc.4+codex.20260908` 后，完全退出并重开 Codex，在原产品项目中新建任务核对版本。产品文件和原配置保留。以后会员在进入星空业务时获得新版提醒，确认后更新，不常驻、不自动安装。

## 验证情况

发行回归 63 项、业务 104 项及 15 个子测试通过，发码助手 19 项测试与隐藏窗口检查通过。Windows 真实 CLI 隔离 rc.3→rc.4 更新、重复安装、配置保留通过；另以原码不含新版密钥的场景验证自动获取签名凭证并安装，测试 HTTP 传输为夹具。两平台包解密后的业务一致，8 份随包说明一致，16 项说明篡改被拒绝，rc.3 附件保留。

以上不代表 用户设备已经完成升级。Mac 实机更新、新任务完整业务执行与实际 Token 节省尚待验证。安装包仍需要官方 Codex 与 Python 3.11+。
