# 星空 Codex · 会员更新与固定版本试用

从 **2.6.0-rc.4** 开始使用会员加密更新凭证。公开下载不等于获得业务使用权，安装仍需作者签发的本机授权。

| 权益 | 固定版本试用 | 服务期会员 |
| --- | --- | --- |
| 已授权安装的版本 | 可以继续使用 | 可以继续使用 |
| 新版本提醒 | 不推送 | 服务期内，进入星空业务时检查并提醒 |
| 后续版本安装 | 不包含 | 权益已登记、凭证已同步且有效时可以更新 |
| 每个版本重新领码 | 不适用 | 不需要，保留原激活记录即可 |
| 到期后 | 已安装内容保留 | 已安装内容保留，后续更新需续期 |

## rc.1、rc.2、rc.3 用户第一次接入

旧版更新器没有会员凭证功能。**请直接下载当前完整安装包（现为 rc.8），运行新包里的“安装与更新”。** 只在旧界面点“检查新版”不能完成这次兼容迁移，也不要把单个新脚本覆盖进旧签名包。已装 rc.4 的有效会员不必走这一节，直接看下文“以后如何更新”。

1. 保存当前工作，按系统下载 [Windows ZIP](https://github.com/wenjiany312-hub/starsky-amazon-codex-releases/releases/download/v2.6.0-rc.8/Starsky-Codex-2.6.0-rc.8-windows.zip) 或 [macOS ZIP](https://github.com/wenjiany312-hub/starsky-amazon-codex-releases/releases/download/v2.6.0-rc.8/Starsky-Codex-2.6.0-rc.8-macos.zip)。不要选 Source code。
2. **完整解压**。Windows 双击 `安装与更新.bat`；Mac 运行 `安装与更新.command`，打不开时在终端输入 `bash ` 后拖入该文件并回车。
3. 安装器读取本机原授权，并从 GitHub 获取只供该激活记录使用的加密更新凭证。已登记的有效会员会显示“会员更新权限已自动核验，无需重新输入授权码”。
4. 最后看到 `安装完成：2.6.0-rc.8+codex.20260909` 才算安装成功。完全退出并重开 Codex，在原产品项目中新建任务，核对实际加载版本。

请保留 `~/.starsky-codex/`、产品目录和原配置。Windows 的 `~` 是当前系统用户目录；更换 Windows 用户或删除原激活记录会影响自动识别。找不到原记录时可以在安装器里粘贴自己的**原始 SKYC1 授权码**再核验，不必先领取新版码。

## 以后如何更新

作者发布新版本时，同步有效会员的加密凭证。会员在 Codex 中使用“启动星空”入口、进入业务时检查更新；发现有权限安装的新版本才提示。用户保存工作、查看说明，再运行安装包中的“检查新版”完成更新，最后重启 Codex 并新开任务。

这是进入业务时检查并提醒，不是后台常驻的消息推送，也不会无人确认就自动安装。Codex 插件详情页未显示更新按钮，不等于会员失去权益。网络异常会提示本次未能确认；继续使用旧版，不把网络错误解释为到期。

## 续费、换机和异常

- **会员续费：**作者更新原设备的会员期限并同步凭证；原会员激活记录继续有效，无需逐版输入新码。试用转会员属于开通会员，需要按作者签发的会员码激活一次。
- **换电脑：**每台设备单独授权；Windows 与 Mac 采用同一会员规则，机器码不同。
- **提示暂无更新许可：**可能是尚未登记为会员、已到期、使用了另一条原激活记录，或作者尚未同步。联系作者提供版本、平台、机器码末六位和错误文字，不要公开完整授权码。

授权码、`activation.json` 和 `license.json` 都应私下保存。GitHub 仅存加密凭证和签名，不含公开的会员姓名、机器码或完整授权码。模型额度、Codex 账号与第三方 MCP 服务另行办理。

Windows 隔离升级和密码学校验不能代替每台真实设备安装验收；Mac 实机和新任务业务结果仍需测试，因此本版保持 Pre-release。
