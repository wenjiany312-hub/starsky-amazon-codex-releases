# S5 店铺运营终端

接通自己的 Amazon Ads API 和 SP-API 后，在本机查看店铺经营、广告、文案和库存。当前支持美国/英国站，按站点分别展示金额与日期。

## 第一次使用

更新至 rc.14，重开 Codex 后输入：

> 启动星空 S5，帮我准备本地店铺运营看板。先检查我的 Ads API 与 SP-API 配置，密钥不要显示在聊天里。

Codex 会定位本机 Node 与已安装 Data 插件的路径，在插件版本目录外创建运营工作区。每站填写自己的 API 配置指针，先做只读接入核验，再采集数据并打开本地看板。安装星空本身不代表 API 已授权或外部依赖已准备好。

看板可查看：店铺总览、出单明细、广告诊断、商品与文案、文案建议、库存补货、成本与收益、待审核、优化复盘。

## 商品亮点怎么补录

1. 打开“商品与文案”，选择产品的“查看明细”。
2. 在“商品亮点 · 人工录入”处点击“录入商品亮点”。
3. 填入当前内容，点击“保存到本地”。以后可查看、修改或清空。

手录内容按店铺、站点、Seller、ASIN、SKU 保存，不被拉取数据或插件升级覆盖。它会明确标为人工录入，**不会自动提交亚马逊**。接口字段与手录记录分开保留，多窗口修改有版本冲突检查。

## 看数字时的口径

- “完整日”是各站点已经结束的当地自然日；“当地今日”仅截至采集时点。
- 从销售卡片可查看出单商品和数量。SKU 涉及订单数不能相加当作全店独立订单数。
- 广告归因销售不等于全店销售。当前广告数据主要为 SP，最近几日可能继续补记归因。
- SIF 的词量、流量份额和排名是第三方信号；接口未返回的字段保持为空。
- 成本为可选项，可从成本页下载模板。成本结果是输入范围内的估算贡献，尚需核对税费、退款、仓储及结算差异。
- 补货首版按 60 天交期与 15 天安全缓冲估算，参数可调整。在途数量未确认前不生成最终采购数量。

## 定时与人工审核

可在自己的 Codex 任务中登记定时跟进。当地午夜对应北京时间：美国夏令时 15:00、冬令时 16:00；英国 07:00、08:00。09:00 汇总当时已完成的数据。计算机和运行环境需可用，异步报表未完成时会保留等待状态。

建议展示修改前后值、理由、证据与待补参数。审核可批准或拒绝，批准后导出候选；**当前没有后台一键执行**。分时调价、自动找词并投放将在后续单独完善和验证。

不要把个人 API 配置、运营目录、报表、成本表或授权码上传 GitHub。反馈问题时只提供脱敏后的错误码、版本、站点与操作步骤。
