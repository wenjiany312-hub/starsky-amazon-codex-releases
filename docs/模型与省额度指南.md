# 模型与省额度指南

适用版本：2.6.0-rc.10，更新日期：2026-09-10。以下是星空业务建议，尚未完成同题模型成本对照，不是官方亚马逊能力排名。用 Pi、DeepSeek、MiniMax、MiMo、GLM 等单一模型（或主模型+视觉辅助）时，看到 Astra / Terra 这行直接忽略，用当前模型继续。

| 任务 | 起步建议 | 升档条件 |
|---|---|---|
| 资料、规格、词表整理；日常巡检；S5 接入检查 | 5.6 Terra 中 | 多来源矛盾或复杂异常转 Astra 中 |
| S1 综合选品分析、S2 文案、S3 视觉策划、S4 广告方案、S5 异常归因 | 6 Astra 中 | 明确影响决策的证据冲突或复杂约束才升高 |
| 指定标题/句子/格式小改 | 5.6 Terra 中 | 新声明缺证据先补资料，不重跑全链 |
| 复杂策略复核、跨 Skill 疑难问题 | 6 Astra 高 | 仍存在明确难点再考虑 xhigh |
| Hash、Bulk 编译、字段校验、固定渲染 | 现有确定性脚本 | 高档模型不取代脚本校验 |

想少切换时，一个完整分析阶段可以用 Astra 中；纯资料整理和常规巡检用 Terra 中。已有验证稳定的 Sol 任务可继续保留；Luna 适合规则固定、能抽查或自动校验的大批量任务。保留用户当前选择，插件只给建议，不自动切换模型。

## 执行方式

- 默认日常模式完成用户已授权的本次范围，无须反复回复“继续”。选款、预算、真实关键词导出、硬缺数和审核仍按业务规则停下。
- 需要课堂演示时明确说“salon_live，逐步教学”，每步有简短步骤卡并等待。
- 指定字段小改不重新扩池或导词；新建 Listing、重新定位或词库重建仍完整执行 S2 门禁。
- 全链入口按当前阶段查参考文件，不必每轮通读其他阶段和历史案例。完整证据仍进入报告，聊天只保留本轮结论和必要动作。
- 使用已有状态与交接文件恢复工作，避免为升档把全部任务从头重做。
- S5 先做接入检查，再巡检。没有领星或 SP-API（LWA）时只允许文件投喂降级快照；薄样本只出观察，不准写成“纯浪费”或直接暂停。

## 额度与验证

优先使用标准速度。Fast 是速度设置，high 是推理档位；它们与模型名称是三个不同选择。套餐额度还受上下文、推理、工具调用与缓存影响，截图中的美元成本不能直接换算成你的套餐百分比。[官方计费](https://learn.chatgpt.com/docs/pricing)

实验性上下文管理是个人环境可选项，本安装器不自动改写 Codex 全局实验配置；先确认当前客户端支持，备份原配置并在新任务验证。[官方配置](https://learn.chatgpt.com/docs/config-file/config-reference)

这次可验证的是入口文档精简与软件回归，不是实际 Token 节省。请用相同资料比较一次合格交付的完整消耗，包含提问、重试和返工；缺少计量数据时不要估成零。[官方 Skill 说明](https://learn.chatgpt.com/docs/build-skills)
