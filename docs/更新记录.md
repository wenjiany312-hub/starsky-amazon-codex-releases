# Codex 版更新记录

## 2.6.0-rc.2 · 2026-09-05 · 会员测试版

- Windows/Mac 同时更新，36 个 Skill 来自同一份加密业务包；每包增加四份完整离线说明（HTML + TXT），覆盖口令、MCP 配置与优惠购买入口。
- S1 报告在标题后优先展示产品图片和可行性判断、理由、限制、下一步；保留完整证据正文。
- 保留 S1 两条各九步路线；逐步展示进度、产物和用户动作。正式跨阶段给出新任务提醒、模型建议与完整交接口令。
- S2 先评审 20 个独立同款/同类候选 ASIN 并取得确认，再输出可复制清单和导出指引；停下等用户放回原始 XLSX/CSV，之后才清洗、确认分类和写文案。真实不足需说明并取得明确范围确认，不准凑数。
- 词包生成/验证增加竞品池、用户导出清单和文件摘要检查，缺材料或输入变动时拒绝通过；旧成果保留为待复核初稿。
- 更新 GPT-6 Astra、5.6 Sol/Terra/Luna 的阶段选择建议；用户自行切换，推荐不等于同条件模型性能实测。
- 修正跨时区授权日期、Mac 官方应用内置 CLI 探测；依赖安装跳过缓存并补齐既有业务脚本依赖。
- 本地发行回归 48 项、业务 104 项及 15 个子测试通过；Windows 隔离首装、rc.1→rc.2 更新及配置保留通过。双平台包加密、摘要和说明完整性检查通过。
- rc.2 Mac 实机更新、两平台新任务加载和完整 S1/S2 实跑仍待会员反馈验证；保持 Pre-release，不声明正式稳定版通过。

升级需领取对应 rc.2 授权码。已安装版本到期仍可使用及接收更新提醒，安装新版需要对应有效授权。

## 2.6.0-rc.1 · 2026-09-05 · 双平台预览

- 原私有开发仓保留，新增独立 Codex 公开介绍与下载仓。
- Windows/macOS 基于同一业务快照；从旧 Mac 2.1.0 补齐 5 个 S1 Skill、入口与编排名称、目录契约、S5 巡检和阈值模板。
- 独立 Codex 本机授权，正常首装/更新需联系作者；到期保留已安装版本使用权。
- 公开业务载荷改为 AES-256-GCM 密文；对应版本解密密钥仅通过私下签发的授权码交付，公开包不携带明文业务 ZIP 或密钥。
- Python 业务依赖置于独立环境，领星配置置于版本缓存之外；失败返回非零，包文件和更新清单带摘要/签名。
- 当前使用 ZIP + 平台脚本入口，未声称提供签名 exe/dmg。
- Mac 实机、两种 Mac CPU 架构、官方 Codex 真正新会话和完整业务链尚待验收；当前发布明确为预览版。

该版本不是对原开发仓的原地修改。原 Mac ZIP 和原私有仓均保留。
